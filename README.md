## 🚀 About AdventJS

**[AdventJS](https://adventjs.dev/)** is an initiative by **[@midudev](https://github.com/midudev)** consisting of 25 days of programming challenges (from December 1st to 25th). It's a fun way to improve logic and programming skills using `JavaScript`, `TypeScript`, or `Python`.
